# Mission: Deploying Static Web Applications to Production (Vercel & GitHub Pages)

## Why
Master the independent end-to-end process of deploying static React/Vite web applications to Vercel and GitHub Pages, understanding the Git-driven Continuous Deployment lifecycle and how to troubleshoot real-world deployment issues.

## Success looks like
- Successfully connect a GitHub repository to Vercel and trigger an automated production deployment.
- Configure GitHub Actions to publish a GitHub Pages mirror.
- Understand the build and deployment lifecycle: `git push` -> webhook -> remote build (`npm run build`) -> CDN distribution.
- Independently verify that the deployed site, SSL certificate, and PWA assets load properly on mobile devices.

## Constraints
- 100% Free tiers only (Vercel Hobby, GitHub Free).
- Single-user personal application with China GFW considerations.

## Out of scope
- Managing paid enterprise CDNs, custom Kubernetes clusters, or complex backend microservices.
