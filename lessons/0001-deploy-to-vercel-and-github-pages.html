Lesson 0001 • Production Deployment

การ Deploy เว็บไซต์ขึ้น Vercel และ GitHub Pages ด้วยตนเอง

เข้าใจหลักการ Git-Driven Continuous Deployment (CI/CD) และขั้นตอนคลิกจริงที่หน้าเว็บ

🧠 1. ทำความเข้าใจภาพรวม (The Mental Model)

การ Deploy สมัยใหม่ไม่ได้ใช้วิธีโยนไฟล์ผ่าน FTP เหมือนในอดีต แต่ใช้โมเดล Git Push → Auto Build → Edge CDN ซึ่งเครื่อง Server ของผู้ให้บริการจะทำหน้าที่เป็นคนงานช่วย Build และเผยแพร่เว็บให้อัตโนมัติ:

วงจรการ Deploy เว็บไซต์อัตโนมัติ (CI/CD Pipeline)
💻 โค้ดในเครื่องคุณ
Edit & Commit
→
🐙 GitHub Repository
JARNBOY/ChinaStaticWebPlanTrip
→
⚡ Vercel / GitHub Actions
รัน `npm run build`
→
🌍 Edge CDN
Online 24/7 (มี SSL ฟรี)
💡 ข้อดีของท่านี้: หลังจากที่คุณเชื่อมต่อครั้งแรกสำเร็จแล้ว ต่อไปเวลาคุณแก้ข้อมูลแพลนเที่ยวหรือเพิ่มวันใหม่ คุณเพียงรันคำสั่ง git push บรรทัดเดียว เว็บออนไลน์จะอัปเดตเองภายใน 30 วินาที!

▲ 2. ขั้นตอนการ Deploy บน Vercel (เว็บหลัก - ใช้เวลา 1 นาที)

เนื่องจากโค้ดได้ถูก Push ขึ้น GitHub เรียบร้อยแล้ว ขั้นตอนที่คุณต้องทำผ่านหน้าจอ Browser มีดังนี้:

1

เข้าสู่ระบบ Vercel

เปิดเว็บไซต์ vercel.com แล้วกด Sign Up หรือ Log In โดยเลือกปุ่ม "Continue with GitHub"

2

สร้าง New Project

หลังจากล็อกอินเข้ามาที่ Dashboard ให้กดปุ่ม "Add New..." ที่มุมขวาบน แล้วเลือก "Project" (หรือเปิดตรงไปที่ vercel.com/new)

3

Import Git Repository

ในช่องค้นหาใต้หัวข้อ Import Git Repository คุณจะเห็นชื่อ ChinaStaticWebPlanTrip ให้กดปุ่ม "Import" สีดำข้างชื่อโปรเจกต์

4

ตรวจสอบการตั้งค่า (Vercel จัดการให้อัตโนมัติ)

Vercel จะตรวจจับพบไฟล์ vercel.json และ vite.config.ts ในโปรเจกต์ของคุณอัตโนมัติ:

  • Framework Preset: Vite
  • Root Directory: ./
  • Build Command: npm run build
  • Output Directory: dist

(ไม่ต้องแก้อะไรเลย ใช้ค่าเริ่มต้นที่ระบบตรวจเจอได้ทันที)

5

กดปุ่ม "Deploy"

กดปุ่มสีฟ้า "Deploy" ระบบจะดึงโค้ด, ติดตั้ง Dependencies, รัน TypeScript check และ Build PWA พร้อมแสดงภาพพลุเฉลิมฉลอง 🎉

คุณจะได้ URL ทันที เช่น https://china-static-web-plan-trip.vercel.app

🐙 3. ขั้นตอนเปิดใช้งาน GitHub Pages (เว็บสำรอง)

เราได้เตรียมไฟล์ .github/workflows/deploy.yml ไว้ใน Git แล้ว สิ่งที่คุณต้องทำมีเพียงการคลิกเปิดสวิตช์ใน GitHub Settings:

1

เปิดหน้า Settings ของ Repo

เปิดลิงก์: github.com/JARNBOY/ChinaStaticWebPlanTrip/settings/pages

2

เปลี่ยน Source เป็น GitHub Actions

ใต้หัวข้อ "Build and deployment" ที่ช่อง Source ให้เปลี่ยนจาก "Deploy from a branch" เป็น "GitHub Actions"

3

ดูสถานะในแท็บ Actions

เปิดแท็บ Actions (github.com/JARNBOY/ChinaStaticWebPlanTrip/actions) จะเห็น Workflow "Deploy to GitHub Pages" กำลังทำงาน เมื่อขึ้นเครื่องหมายถูกสีเขียว เว็บสำรองของคุณจะพร้อมใช้งานที่ https://JARNBOY.github.io/ChinaStaticWebPlanTrip/

🔄 4. ต่อจากนี้ ถ้าอยากแก้ข้อมูล ต้องทำอย่างไร?

เมื่อคุณปรับแก้สถานที่เที่ยวใน src/data/shanghai/day01.ts หรือเพิ่มวันใหม่ คุณทำเพียง 3 สเต็ปใน Terminal:

# 1. ดูไฟล์ที่แก้
git status

# 2. ทำการ Commit
git add .
git commit -m "update: add day 2 itinerary"

# 3. ส่งขึ้น Cloud
git push origin main

ทันทีที่คำสั่ง git push ทำงานเสร็จ ทั้ง Vercel และ GitHub Pages จะดึงโค้ดใหม่ไป Build และอัปเดตหน้าเว็บจริงให้คุณพร้อมกันทั้ง 2 เซิร์ฟเวอร์แบบอัตโนมัติ!
